# Прокси ИИ-помощника

Cloudflare Worker `tko-ioo-ai` хранит ключ Anthropic в секрете
`ANTHROPIC_API_KEY`. Браузер передаёт полный документ нормативов, Worker
обращается к мультимодальной модели Haiku 4.5 и возвращает записи нормативов.
Реестр ИОО по-прежнему передаётся только образцом для определения столбцов.

На сайте также есть режим «API-ключ в браузере»: с заданным ключом браузер
обращается в Anthropic напрямую, и этот Worker не используется. Для включения
этого режима не нужно менять секреты или заново развёртывать Worker.

## Обновление существующего Worker

Сначала обновите Worker, затем публикуйте сайт. Старый Worker не понимает
задачу `norms-extract`. Обновление кода сохраняет существующий API-ключ.

Из корня проекта:

```bash
npx wrangler deploy --config worker/wrangler.toml
```

Нужно войти в тот же аккаунт Cloudflare, где находится `tko-ioo-ai`:
`npx wrangler login`. Для автоматического развёртывания используются
`CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` с правами редактирования Worker.
Не добавляйте значения этих переменных в репозиторий.

В исходном коде есть импорты: не копируйте один `index.js` в редактор Cloudflare.
Для обновления через браузер сначала соберите один файл:

```bash
npx esbuild worker/index.js --bundle --format=esm --outfile=/tmp/tko-ioo-worker.js
```

Откройте Cloudflare → Workers & Pages → `tko-ioo-ai` → Edit code,
замените код собранным файлом и нажмите Deploy. Секрет не нужно вводить заново.

## Первое развёртывание и замена ключа

```bash
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY --config worker/wrangler.toml
npx wrangler deploy --config worker/wrangler.toml
```

При вводе секрета вставьте ключ Anthropic в интерактивное поле. В Cloudflare UI:
Worker → Settings → Variables and Secrets → `ANTHROPIC_API_KEY` → Edit → Deploy.
Сайт использует `https://tko-ioo-ai.kamegaev.workers.dev`; другой адрес задаётся
на шаге 1 в блоке «Свой прокси».

## Протокол

| Задача | Вход | Результат |
| --- | --- | --- |
| `norms-extract` | `document`: исходный PDF/изображение (base64) или полный текст DOCX/Excel с таблицами и изображениями | `complete`, `entries`, `warnings`, `reason` |
| `registry-markup` | `tables`: первые строки листов реестра | лист, строка заголовка и роли столбцов |
| `norms-markup` | прежний формат таблиц | прежний ответ; оставлен для совместимости со старым сайтом |

Каждый элемент `entries` содержит `name`, `context`, `unit`, `mass`, `volume`
и `source: {location, quote}`. Отсутствующая величина — `null`; существующая —
`{value, unit, period, quantity}`. Масса: `kg/t/g`, объём: `m3/l`, период:
`year/month/day`, количество расчётных единиц строго положительно.

Пример ответа модели:

```json
{
  "complete": true,
  "entries": [{
    "name": "Жилые дома",
    "context": "Сельские населённые пункты",
    "unit": "на 1 человека",
    "mass": {"value": 0.247027, "unit": "t", "period": "year", "quantity": 1},
    "volume": {"value": 2.073, "unit": "m3", "period": "year", "quantity": 1},
    "source": {"location": "Приложение, строка 5", "quote": "2,073 м³; 0,247027 тонн на человека в год"}
  }],
  "warnings": [],
  "reason": "Все приложения обработаны"
}
```

Клиент программно приводит значения к кг/год и м³/год на одну расчётную единицу.
PDF передаётся в Anthropic как `document`, изображения — как `image`.
Для извлечения выделено до 32 000 выходных токенов. Ответ с `stop_reason=max_tokens`
отклоняется целиком. Клиент также не применяет ответ с `complete=false`, пустой
список, отрицательные числа, неизвестные размерности или записи без источника.
Это проверка структуры, а не доказательство точности распознавания.

## Ограничения и расходы

- Исходный документ: до 16 МБ; запрос: до 24 МБ с учётом base64.
- Текстовое представление: до 400 000 символов; до 50 вложенных изображений.
- До 1000 нормативов; тайм-аут клиента 5 минут.
- Образец реестра/старой разметки: до 1 МБ и прежние ограничения таблиц.
- Ограничение частоты: 20 запросов в минуту с одного адреса.

Документы не усекаются незаметно: большой файл нужно разделить на части.
Действуют также лимиты Anthropic на страницы PDF, разрешение изображений и
контекст модели. Ошибка провайдера возвращается пользователю.

Полное визуальное чтение и вывод всех нормативов расходуют больше токенов,
чем прежняя разметка. Стоимость зависит от страниц, изображений и объёма результата.
Запрос запускается при загрузке нормативов и при явном повторном запуске.

Разрешённые адреса сайта заданы в `ALLOWED_ORIGINS` в `index.js`.
CORS ограничивает браузеры, но не заменяет аутентификацию публичного endpoint.
Текст задачи и схема ответа заданы на сервере. Содержимое документа трактуется
как данные, а не инструкции для модели.
