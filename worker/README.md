# Прокси для помощника разметки

Небольшой Cloudflare Worker: хранит ключ Anthropic и обращается к модели вместо
браузера. Нужен потому, что сайт статический — ключ, вписанный в его код, был бы
виден всем.

## Развёртывание

Понадобится учётная запись Cloudflare (бесплатного тарифа хватает с большим
запасом) и ключ Anthropic API.

```bash
npm install -g wrangler
wrangler login

cd worker
wrangler secret put ANTHROPIC_API_KEY   # ключ вводится в консоли, в файлы не попадает
wrangler deploy
```

На `wrangler secret put` до первого развёртывания появится вопрос:

> There doesn't seem to be a Worker called "tko-ioo-ai".
> Do you want to create a new Worker with that name and add secrets to it?

Отвечайте **Yes**: воркера с таким именем ещё нет, и wrangler создаёт заготовку,
чтобы положить в неё ключ. Следующая команда `wrangler deploy` зальёт в эту
заготовку код; ранее заданный секрет при этом сохраняется.

Если `wrangler deploy` откажется принимать блок `[[unsafe.bindings]]` из
`wrangler.toml` — удалите этот блок и повторите команду. Он задаёт ограничение
частоты обращений, и код к его отсутствию готов.

`wrangler deploy` напечатает адрес вида
`https://tko-ioo-ai.<ваш-поддомен>.workers.dev`. Свой адрес указывается в
приложении: шаг 1 → «Помощник разметки» → «Свой прокси» → поле адреса. Адрес
прокси, развёрнутого для этого приложения, вписан в `js/ai/client.js`
(`DEFAULT_ENDPOINT`) и используется по умолчанию.

## Что уходит в модель

Только подписи таблиц и первые шесть строк каждой из файла нормативов —
несколько килобайт. Реестр ИОО не отправляется вообще: в этой задаче он не
участвует. Точный текст запроса приложение показывает перед отправкой.

## Ограничения прокси

| Ограничение | Значение |
| --- | --- |
| Разрешённые адреса сайта | `ALLOWED_ORIGINS` в `index.js` |
| Размер запроса | 64 КБ |
| Таблиц / строк / столбцов в образце | 12 / 6 / 12 |
| Частота обращений | 20 в минуту с адреса |
| Доступные задачи | только `norms-markup` |

Текст запроса к модели и схема ответа заданы в `index.js`, а не приходят от
клиента: через прокси нельзя обратиться к модели с произвольным запросом и
израсходовать ваш ключ на посторонние задачи.

Адрес прокси публичен — он вписан в исходный код и виден на опубликованном
сайте. Ограничение по источнику (CORS) защищает только браузер: обратиться к
прокси напрямую, минуя сайт, может любой, кто знает адрес. Верхняя граница
ущерба — 20 запросов в минуту к самой дешёвой модели. Если этого недостаточно,
прокси можно закрыть паролем: строка в секретах Cloudflare, которую приложение
передаёт вместе с запросом.

Если публикуете сайт на другом адресе — добавьте его в `ALLOWED_ORIGINS`
и разверните воркер заново.

## Стоимость

Разметка одного файла — примерно 2–4 тысячи входных токенов и несколько сотен
выходных на модели Haiku 4.5, то есть доли копейки за запуск. Приложение
запоминает применённую разметку, поэтому повторный разбор того же файла
обращения к модели не требует.
